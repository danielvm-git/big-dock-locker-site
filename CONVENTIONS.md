# Conventions

This document outlines the conventions for all AI agents working on this project.

## Output

- All planning, specifications, and reports MUST be written to the `specs/` directory.

## Defensive Code

This project uses the following defensive coding practices. Agents must be familiar with them and apply them where appropriate.

- **Graceful degradation**: Provide a degraded but functional experience when parts of the system are down.

## Bigpowers Workflow

This project follows the bigpowers methodology. All work must be performed using the bigpowers skills.
